# TTG 2026 — Appointment Automation

Automated meeting request scripts for TTG Rimini 2026.
Runs two accounts simultaneously: Best Holidays in Italy and Borracce di Poesia.

## Environment variables (set in Railway dashboard)

| Variable | Description |
|---|---|
| `BHI_EMAIL` | BHI login email |
| `BHI_PASSWORD` | BHI login password |
| `BDP_EMAIL` | Borracce di Poesia login email |
| `BDP_PASSWORD` | Borracce di Poesia login password |

## Schedule

- Window opens: 8 September 2026 at 16:00 CET
- Window closes: 8 October 2026 at 10:00 CET
- Wave frequency: every 24 hours
- Both scripts run simultaneously inside one Railway service
